# 🎓 班级专属随机点名系统 (Class Roll-Call System)

本项目专为杭州市财经学校金融254班定制开发。通过纯前端网页（HTML/JS/CSS）结合 Python 封装，实现带有视觉特效的独立桌面级抽签点名功能。

## ✨ 核心特性

* **专属定制**：内置 39 名同学的完整名单与学号，公平随机抽取。
* **视觉效果**：支持流光背景与点名成功后的全屏烟花特效。
* **独立运行**：摆脱浏览器外框束缚。通过 PyWebView 封装，在 Windows 系统下双击 `.exe` 即可作为独立桌面软件全屏运行。
* **云端编译**：借助 GitHub Actions 全自动云端打包，无需在本地电脑配置 Python 环境。

## 📂 文件结构

* `index.html`：点名系统的核心网页逻辑、视觉特效与 39 人名单库。
* `main.py`：Python 窗体控制脚本，负责调用系统内核渲染网页。
* `icon.png`：软件专属图标。
* `.github/workflows/main.yml`：GitHub Actions 全自动云端打包工作流配置文件。

## 📥 如何下载 Windows 独立运行版 (.exe)

如果你需要获取最新打包的 Windows `.exe` 可执行文件，请按照以下步骤操作：

1. 点击仓库顶部导航栏的 **[Actions]** 标签。
2. 在左侧菜单中点击 **Build Windows EXE**。
3. 点击列表中最上方（最新）带有绿色对勾 `✓` 的运行记录。
4. 滚动到页面最下方的 **Artifacts (工件)** 区域。
5. 点击下载 **`Class-Roll-Call-EXE`** 压缩包。
6. 解压后即可获得纯正的独立可执行文件，拷入 U 盘即可带去任意 Windows 教室双击使用。

## 🛠️ 本地开发与修改说明

如需修改班级名单：
1. 打开 `index.html` 文件。
2. 定位到包含学生姓名的数组代码段。
3. 修改对应的名字或学号后保存。
4. 将修改后的 `index.html` 提交至本仓库，GitHub Actions 将在后台自动为你重新生成最新的 `.exe` 软件。
